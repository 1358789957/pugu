# 谱骨

上传歌曲，浏览器里扒主旋律和和弦，导出库乐队能直接拖进去的 MIDI。

不上传服务器，人声分离 / Basic Pitch 转音符 / 和弦都在本地算。

## 能干什么

- 拖入 MP3 / WAV，或哼唱录音
- 成曲先拆人声再扒旋律
- 钢琴卷帘、五线谱、词谱（上音符 / 中歌词 / 下和弦）
- 检测调性、速度、和弦进行
- **按谱播放**：合成旋律 + 和弦垫，光标跟着谱走
- 导出 Type-1 MIDI（速度轨 + 旋律轨 + 和弦轨）和干声 WAV

## 本地运行

```bash
npm install
npm run dev
```

打开 http://127.0.0.1:8080

拖入音频，或点「试听示例」扒《小星星》。扒完后播放条默认是「旋律」：听的是谱上的音和和弦，不是原曲。点五线谱 / 词谱 / 卷帘可定位；空格播放暂停。

## 怎么读谱

扒完后音符会吸到检测出来的 BPM 格子上（默认 16 分），再按 4/4 切开：

- **五线谱**：调号、拍号、小节线、休止、常用时值（16 / 8 / 4 / 附点 / 2）、八分符杠、跨小节连音。和弦标在小节上方。
- **词谱**：简谱数字，一行四小节；上音符、中歌词、下和弦，小节线对齐。下划线是八分 / 十六分，横线是延音，`0` 是休止。
- **钢琴卷帘**：同一套小节尺。点空白处定位播放。

改 BPM 或打开「吸附节拍」会按新速度重新靠格。屏幕上的谱仍按拍点排；导出的 MIDI 用分析出的原始起止时间（按 1 tick 四舍五入），不吸到 16 分，方便在库乐队钢琴帘里微调。

## 库乐队

1. 扒完点「库乐队 MIDI」
2. 把 `.mid` 拖进库乐队（Mac）或经「文件」导入（iPhone）——应是可编辑的软件乐器音符，不是音频
3. 工程速度改成检测出来的 BPM
4. 一般会有两条轨：旋律（精细时值）+ 和弦垫底（按拍）

示例扒谱在 [examples/hirumawari](./examples/hirumawari)：词谱、和弦进行；完整 MP3 / MIDI / 干声可从首页示例区下载。

## 技术

TanStack Start + Web Audio。旋律用 Spotify Basic Pitch（TensorFlow.js，浏览器本地推理）出音符，人声仍是 HPSS + 中置提取，和弦是色度模板 + Viterbi。谱面量化在检测到的速度和拍点上完成，播放和 MIDI 用同一套分析音符；MIDI 不重新吸到 16 分格子。
