# 昼回のメモリー · 扒谱成品

G 大调 · 117 BPM · 全曲 4:38

简谱是 **1=C 固定调**（C=1, D=2, E=3, F=4, G=5, A=6, B=7）。不是首调，没有 1=G。

第一句是同一条相对旋律，从主音起，两调写法不同，不要混用：

- **C 大调核对**（唯一 C 测）：
  - 第一句 `1 2 3 2 3 4 3 2 7 1 2 2 7 1` = C D E D E F E D B C D D B C
  - 第二句 `6 7 1 1 1 1 1 7 5 1 2 1 3` = A B C C C C C B G C D C E（`671111 | 17512 | 13`）
- **G 大调 固定调**（本曲录音，不要当 C 测）：第一句 `5 6 7 6 7 1 7 6` = G A B A B C B A（G=5，因为 1=C）

录音在 G。C 大调核对：concert MIDI 降 7 再写成固定调。G 录音直接固定调不是 C 测。
